# Skill: Quality Gate 🛡️

## Propósito
Actuar como el último filtro de excelencia antes de que cualquier mensaje sea enviado al usuario Abrahan Pulido.

## Instrucciones para el Agente
Si se te solicita aplicar este skill:
1. **Verificación de Fuentes**: Asegúrate de que cada afirmación técnica o de marca esté respaldada por `brand-guide.md`, `MEMORY.md` o las lecciones en `LESSONS.md`.
2. **Eliminación de Alucinaciones**: Si no hay datos ciertos, el agente DEBE decir "No tengo información específica sobre X" en lugar de inventar.
3. **Tono de Ingeniería**: Verifica que el lenguaje sea de "Arquitecto a Arquitecto".
4. Valida que la respuesta resuelva el 100% de la duda del usuario.

## Lista de Verificación (Checklist)
- [ ] ¿Cita fuentes internas?
- [ ] ¿Cero clichés de IA generativa?
- [ ] ¿Técnicamente preciso?
- [ ] ¿Resolución directa del problema?
