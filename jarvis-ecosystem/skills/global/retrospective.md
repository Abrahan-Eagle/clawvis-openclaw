# Skill: Retrospective (Auto-Aprendizaje) 🧠

## Propósito
Analizar errores o correcciones del usuario para evitar repetirlos en el futuro.

## Instrucciones para el Agente
Cada vez que el usuario corrija tu comportamiento o información:
1. Identifica el error cometido.
2. Identifica la causa raíz (ej. instrucciones ambiguas, falta de contexto, alucinación).
3. Escribe una entrada en el archivo `LESSONS.md` del workspace actual siguiendo este formato:
   - **Error:** [Descripción breve]
   - **Causa:** [Por qué sucedió]
   - **Accion:** [Qué cambiarás en tu proceso para que no vuelva a pasar]
4. Si el cambio requiere una actualización en tu `SOUL.md` o `AGENTS.md`, notifícalo a Jarvis.

## Meta
Reducir la tasa de error por iteración y aumentar la autonomía del ecosistema.
