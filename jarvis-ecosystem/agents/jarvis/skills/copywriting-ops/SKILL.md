# Copywriting Ops

*Adaptado de marketingskills/copywriting para el ecosistema Jarvis*

## Trigger

Usar este skill cuando el agente necesite escribir o revisar copy para:
- Landing pages o paginas de servicios
- Homepage o secciones de producto
- Posts de redes sociales (caption largo)
- Carruseles multi-slide (guion por diapositiva): usar tambien [`carousel-ops`](../carousel-ops/SKILL.md)

**Redes sociales — regla de claridad:** si el encargo es “un post” o “contenido para redes” **sin** decir red ni formato, **preguntar antes** (o proponer 1 opcion por red en bloques separados): canal(es), formato (post vs carrusel vs hilo), si incluye **brief visual** (imagenes, Canva, solo texto). Cada red tiene reglas distintas; no entregar solo un bloque generico como si valiera para todas.
- Propuestas comerciales (seccion de pitch)
- Descripciones de perfil (Workana, LinkedIn)

## Prerequisito obligatorio

**ANTES de escribir cualquier copy, leer:**
`jarvis-ecosystem/.agents/product-marketing-context.md`

Extraer de ahi: audiencia, diferenciadores, voz de marca, objeciones comunes y customer language. No inventar datos que no esten en ese archivo.

## Principios de copy

1. **Claridad > creatividad** -- si el lector no entiende en 5 segundos que haces, fallo.
2. **Beneficios > features** -- el cliente quiere saber que gana, no como funciona por dentro.
3. **Una idea por bloque** -- cada seccion o parrafo tiene un solo mensaje.
4. **Prueba social primero** -- si hay datos, reviews o resultados, usarlos antes de adjetivos.
5. **CTA claro** -- cada pieza de copy debe tener una accion siguiente obvvia.

## Formulas de headline

Usar alguna de estas segun contexto:

| Formula | Ejemplo |
|---------|---------|
| [Resultado] sin [obstaculo] | "Tu app lista sin meses de reclutamiento" |
| [Numero] formas de [beneficio] | "3 formas de acelerar tu proyecto web" |
| [Problema]? [Solucion] | "Tu web no convierte? Optimizamos tu landing en 48h" |
| Para [audiencia] que [situacion] | "Para startups que necesitan un MVP rapido" |

## Estructura de pagina (landing)

```
1. Hero: Headline + subheadline + CTA principal
2. Pain: Describir el problema del cliente (customer language)
3. Solution: Que hacemos y como resuelve el dolor
4. Proof: Resultados, testimonios, logos de clientes
5. How it works: 3 pasos simples
6. FAQ / Objeciones: Resolver las top-3
7. CTA final: Repetir la accion con urgencia suave
```

## Voz de marca (resumen)

- **Tono:** profesional pero cercano
- **Estilo:** directo, orientado a soluciones
- **Evitar:** "disruptivo", "sinergia", "revolucionario", jerga de IA como selling point

## Checklist antes de entregar

- [ ] Lei product-marketing-context.md
- [ ] El headline pasa la prueba de 5 segundos
- [ ] Cada seccion tiene un solo mensaje
- [ ] Hay al menos un CTA visible
- [ ] El copy usa customer language (no jerga interna)
- [ ] Las objeciones estan resueltas en el texto
- [ ] Revise ortografia y que no hay spanglish innecesario

## Output esperado

Entregar el copy completo con:
- Headline + subheadline
- Body text por secciones
- CTAs sugeridos
- Notas sobre donde usar prueba social (si la hay)
