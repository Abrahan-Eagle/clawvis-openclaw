# Page CRO Ops

*Adaptado de marketingskills/page-cro para el ecosistema Jarvis*

## Trigger

Usar este skill cuando el agente necesite:
- Auditar una landing page o pagina de servicios para mejorar conversion
- Revisar la pagina antes de lanzarla
- Proponer mejoras a una pagina existente que no convierte
- Evaluar paginas de competidores para benchmark

## Prerequisito obligatorio

**ANTES de auditar cualquier pagina, leer:**
`jarvis-ecosystem/.agents/product-marketing-context.md`

Extraer: audiencia, pain points, objeciones, customer language para evaluar si la pagina habla el idioma del cliente.

## Framework de 7 dimensiones

Evaluar la pagina en cada dimension con puntaje 1-5 y recomendacion.

### 1. Claridad del mensaje

- ¿El visitante entiende que hacemos en 5 segundos?
- ¿El headline responde "que, para quien, por que"?
- ¿El subheadline refuerza sin repetir?
- **Prueba:** tapar todo menos el hero. ¿Se entiende?

### 2. Relevancia para el target

- ¿El copy usa customer language (no jerga interna)?
- ¿Los ejemplos/casos son relevantes para la audiencia?
- ¿Los pain points mencionados son reales?
- **Prueba:** ¿un prospect diria "esto es para mi"?

### 3. Propuesta de valor

- ¿Los diferenciadores estan visibles?
- ¿Hay comparacion implicita o explicita vs alternativas?
- ¿Se comunica el beneficio, no solo el feature?
- **Prueba:** ¿queda claro por que elegirnos a nosotros?

### 4. Prueba social

- ¿Hay testimonios, reviews, logos, numeros?
- ¿Son creibles y verificables?
- ¿Estan cerca del CTA?
- **Prueba:** ¿un esceptico se convenceria?

### 5. Call to Action

- ¿Hay un CTA primario claro?
- ¿El CTA dice que pasa despues de clickear?
- ¿Esta visible sin scroll?
- ¿Se repite al final de la pagina?
- **Prueba:** ¿el visitante sabe exactamente que hacer?

### 6. Friccion y distracciones

- ¿Hay elementos que distraen del objetivo principal?
- ¿El formulario pide solo lo necesario?
- ¿La navegacion compite con el CTA?
- ¿La pagina carga rapido?
- **Prueba:** ¿hay algo que pueda eliminar sin perder valor?

### 7. Urgencia y motivacion

- ¿Hay razon para actuar ahora (sin ser falsa)?
- ¿El copy transmite confianza?
- ¿Las objeciones estan resueltas antes del CTA?
- **Prueba:** ¿que impide al visitante actuar ahora?

## Prioridades de accion

Ordenar recomendaciones por:
1. **Impacto alto + esfuerzo bajo** (quick wins) -- hacer primero
2. **Impacto alto + esfuerzo alto** -- planificar
3. **Impacto bajo** -- backlog

## Checklist antes de entregar
