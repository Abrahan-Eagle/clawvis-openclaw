# Skill: clawflows-capability-map

## Proposito

Apoyar **ClawFlows CLI** (`clawflows check`, escaneo de capabilities) cuando las skills empaquetadas no declaran `Provides:` en el metadata estandar.

## Contenido

- **Definicion de capabilities:** [CAPABILITY.md](CAPABILITY.md)

No es un skill de negocio (ventas/marketing); es metadata para el registry de automatizaciones.

## Cuando usarlo

Al depurar YAML en `jarvis-ecosystem/automations/` o al extender el mapa de herramientas disponibles para Lobster/ClawFlows.
