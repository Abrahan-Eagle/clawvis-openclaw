# Mapa de capabilities para ClawFlows CLI

Este directorio no es un skill operativo de OpenClaw; solo alimenta `clawflows check` / `scanCapabilities` cuando las skills empaquetadas no declaran `Provides:` en `CAPABILITY.md`.

Las capacidades reales siguen dependiendo de que tengas instalados los CLIs y credenciales (p. ej. `gh`, `gog`, `curl`, skills de ClawHub).

Provides: github, weather, calendar, tts, rss, cron, web-search, curl, jq
