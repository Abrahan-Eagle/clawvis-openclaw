# jmc-adapter

Servicio FastAPI para [Jarvis Mission Control](../../docs/JMC_DESIGN.md): lectura de estado y escritura acotada de modo (`POST /v1/modes/current` con Bearer).

Instalación: desde `jarvis-ecosystem`, `pip install -e jmc/adapter`.

Arranque: ver [`docs/JMC_OPERACION.md`](../../docs/JMC_OPERACION.md).
