# Copia de trabajo de `~/.openclaw` (sin secretos)

Instantánea **sanitizada** para el monorepo [`clawvis-openclaw`](https://github.com/Abrahan-Eagle/clawvis-openclaw): `openclaw.json`, agentes (sin sesiones ni `auth-profiles`), `workspace/` con docs, `cron/`, etc.

**No incluye:** `.env`, `credentials/`, canales, caché, navegador, logs, historial de chat.

En una máquina nueva: copia `~/.openclaw/.env` desde un almacén seguro; no está en Git.
